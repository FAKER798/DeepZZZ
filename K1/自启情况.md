# K1 自启情况

最近核对时间：`2026-08-08 CST`

板卡部署根目录：`/home/z`

## 当前服务

| 服务 | 角色 | 启动命令 | 说明 |
| --- | --- | --- | --- |
| `deepzzz-k1-edge.service` | 主 Web/API 服务 | `/usr/bin/taskset -c 4-7 /usr/bin/python3 /home/z/main.py` | Flask 服务，端口 `7860`，同时按配置启动数据集端口 `7861`。 |
| `day-night-sync.service` | 昼夜/IR-CUT worker | `/usr/bin/python3 /home/z/scripts/day_night.py sync-ircut --sync-camera` | 读取 GPIO35，写 `runtime/state/day_night`，调用 IR-CUT。 |
| `light-pwm.service` | 补光 PWM worker | `/usr/bin/python3 /home/z/devices/lightcontrol.py ...` | 读取 `runtime/state/light_command.json`，写 PWM sysfs 和状态文件。 |
| `temperature-humodity.service` | 温湿度 worker | `/usr/bin/python3 /home/z/devices/temperature_humidity.py ...` | 读取 DHT11，写 `runtime/state/temperature_humidity.json`。 |
| `deepzzz-usb-irq-affinity.service` | USB 中断亲和性 | `/usr/local/sbin/deepzzz-pin-usb-irq` | 将 USB 摄像头 IRQ 固定到 CPU7。 |
| `camera.service` | 板卡系统 camera 初始化 | `/etc/init.d/camera.sh` | 系统服务，通常保留。 |

废弃服务 `camera-hls.service`、`camera-web.service`、`ir-cut.service` 不应再启用。

## 主服务配置

本地 unit 文件：`scripts/deepzzz-k1-edge.service`

关键配置：

```ini
WorkingDirectory=/home/z
Environment=HOST=0.0.0.0
Environment=PORT=7860
Environment=DATASET_CAPTURE_PORT=7861
Environment=ENABLE_POSE=1
Environment=POSE_MODEL=/home/z/.brdk_models/pose/yolov8n-pose-k1-320-int8.onnx
Environment=POSE_PROVIDER=SpaceMITExecutionProvider
Environment=POSE_PROVIDER_FALLBACK=0
Environment=ENABLE_DATASET_CAPTURE=1
Environment=ANALYSIS_WIDTH=320
Environment=ANALYSIS_FPS=10
Environment=AUDIO_DEVICE=plughw:CARD=UACDemoV10,DEV=0
Environment=AUDIO_OUTPUT_DEVICE=plughw:CARD=UACDemoV10,DEV=0
Environment=AUDIO_RATE=16000
Environment=YAMNET_SECONDS=2
Environment=YAMNET_INTERVAL=0.5
ExecStart=/usr/bin/taskset -c 4-7 /usr/bin/python3 /home/z/main.py
```

## 职责边界

主服务负责：

- Flask Web/API
- 最新画面帧/静态文件/音频文件输出
- 摄像头和 AI/audio pipeline 生命周期
- 读取 worker 状态
- 写补光命令文件

独立 worker 负责：

- PWM sysfs 和 pinmux
- DHT11 单总线时序
- GPIO35 昼夜检测
- IR-CUT GPIO 脉冲

主服务不要直接操作 PWM sysfs、GPIO pinmux 或 DHT11 时序。

## 安装/更新

```bash
sudo cp /home/z/scripts/deepzzz-k1-edge.service /etc/systemd/system/deepzzz-k1-edge.service
sudo cp /home/z/scripts/day-night-sync.service /etc/systemd/system/day-night-sync.service
sudo cp /home/z/scripts/light-pwm.service /etc/systemd/system/light-pwm.service
sudo cp /home/z/scripts/temperature-humodity.service /etc/systemd/system/temperature-humodity.service
sudo systemctl daemon-reload
sudo systemctl enable --now deepzzz-k1-edge day-night-sync light-pwm temperature-humodity
```

验证：

```bash
curl http://127.0.0.1:7860/api/healthz
curl http://127.0.0.1:7860/api/status

```
