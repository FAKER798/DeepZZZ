# K1 项目架构说明

本文档记录 `K1/` 当前新架构、运行链路，以及每个目录和关键文件的职责。

## 2026-06-15 重建后的权威边界

当前主路径已经切到 `k1edge/`：

```text
main.py
  -> k1edge.config typed config
  -> k1edge.runtime AppRuntime
  -> k1edge.app Flask HTTP apps
```

兼容边界保持不变：主端口 `7860`，数据集端口 `7861`，主 systemd 服务名 `deepzzz-k1-edge.service`，原有主要 API 路径继续保留。

主服务职责：

- 启动 Flask Web/API。
- 管理摄像头、视觉、音频 pipeline 生命周期。
- 聚合 `/api/status` 和 `/api/healthz`。
- 读取硬件 worker 状态文件。
- 写补光命令文件。

独立 worker 职责：

- `day-night-sync.service`：GPIO35 昼夜检测和 IR-CUT 联动。
- `light-pwm.service`：PWM sysfs、pinmux 和补光实际输出。
- `temperature-humodity.service`：DHT11 读取。

主服务不得直接写 PWM sysfs、GPIO pinmux 或 DHT11 时序。

## 运行链路

### 视频链路

```text
USB 摄像头
  -> devices.camera.CameraPipeline
  -> ffmpeg 只负责快速排空逐帧独立的 MJPEG
     -> Python 容量 1 最新帧槽：旧帧立即覆盖
     -> 10 fps 仅解码槽中最新帧
     -> 高清当前帧：JPEG image2pipe
     -> 低清分析帧：紧凑 BGR24 rawvideo pipe
  -> pipelines.video_pipeline.VideoPipeline
  -> ai.vision_ai.VisionWorker
  -> ai.pose.YoloPoseEngine
  -> k1edge.runtime.VideoRuntime
  -> k1edge.app
     -> /api/preview-snapshot
     -> /api/detections
     -> /api/snapshot
     -> /api/status
```

### 音频/哭声链路

```text
USB 麦克风
  -> devices.mic.ContinuousWaveformRecorder
  -> arecord 持续采集 PCM
  -> pipelines.audio_pipeline.AudioPipeline
  -> 滑动窗口读取最近 yamnet_seconds 秒
  -> ai.audio_ai.YamnetCryDetector
  -> ai.audio_ai.CryStateTracker
  -> k1edge.runtime.AudioRuntime
  -> k1edge.app
     -> /api/status
     -> /api/audio/yamnet
```

### 录音外放验证链路

```text
网页 Audio Playback 控件
  -> POST /api/audio/playback
  -> pipelines.audio_pipeline.AudioPipeline.play_recent_audio()
  -> 优先读取 ContinuousWaveformRecorder 最近 N 秒缓冲
  -> fallback 到 arecord 临时录 N 秒
  -> runtime/audio/playback_<timestamp>.wav
  -> aplay -D <输出设备>
```

当前输入和输出均使用 USB 音频设备 `plughw:CARD=UACDemoV10,DEV=0`。

### 昼夜/IR-CUT 链路

```text
day-night-sync.service
  -> scripts/day_night.py sync-ircut
  -> devices.day_night_gpio
  -> GPIO35 读取昼夜状态
  -> devices.ircut
  -> scripts/ir_cut_control.py
  -> GPIO33/GPIO46 控制 IR-CUT
```

网页昼夜状态：

```text
k1edge.runtime.HardwareRuntime
  -> devices.day_night_sensor.day_night_status()
  -> 优先读取 runtime/state/day_night
  -> fallback 到 runtime/logs/sync_day_night_ircut.log
  -> fallback 到 runtime/state/current_mode
```

## `devices/`

硬件采集和硬件控制边界。原则：只负责拿数据或控制 GPIO，不写业务判断。

| 文件 | 作用 |
| --- | --- |
| `devices/__init__.py` | Python package 标记。 |
| `devices/camera.py` | 摄像头管线。单个 FFmpeg 直接采集，持续覆盖高清 JPEG 和低清 BGR 当前帧，不产生视频流、分片或传输缓存。 |
| `devices/mic.py` | 麦克风录音。包含持续 PCM 采集、一次性录音、音频电平和 wav 写入。 |
| `devices/day_night_gpio.py` | GPIO35 昼夜输入读取，以及联动 IR-CUT 的 watch/sync 逻辑。 |
| `devices/day_night_sensor.py` | 给主网页读取昼夜状态。优先读同步服务写入的状态文件，失败后读同步日志和 IR-CUT 状态文件。 |
| `devices/ircut.py` | IR-CUT H 桥 GPIO 控制。负责 GPIO33/GPIO46 脉冲输出。 |

## `ai/`

AI 推理边界。原则：只关心模型和算力，不关心数据来源和输出方式。

| 文件 | 作用 |
| --- | --- |
| `ai/__init__.py` | Python package 标记。 |
| `ai/runtime.py` | CPU/NPU provider 边界。负责 `SpaceMITExecutionProvider` 注册、provider 顺序和 CPU fallback。 |
| `ai/pose.py` | YOLOv8-pose ONNX 推理、预处理、后处理和骨架绘制。通过 `ai.runtime` 创建 ONNX Runtime session。 |
| `ai/vision_ai.py` | 视觉 worker。只保留最新待处理帧，避免 backlog，统计实际分析 fps。 |
| `ai/audio_ai.py` | YAMNet 推理、连续 PCM 环形缓冲、wav 读写、哭声标签评分和状态平滑。 |

## `pipelines/`

业务流水线层。负责把硬件输入、AI 推理和服务状态串起来。

| 文件 | 作用 |
| --- | --- |
| `pipelines/__init__.py` | Python package 标记。 |
| `pipelines/video_pipeline.py` | 画面流水线。启动摄像头当前帧采集、低清分析和视觉 worker。 |
| `pipelines/audio_pipeline.py` | 音频流水线。启动持续录音、滑动窗口 YAMNet 检测和哭声状态平滑。 |

## `services/`

长期运行状态层。核心状态由 `k1edge.runtime` 聚合，本目录保留资源、活动区域和数据集服务。

| 文件 | 作用 |
| --- | --- |
| `services/__init__.py` | Python package 标记。 |
| `services/resources.py` | 资源监控。Linux 上读取 CPU、内存、温度、`main.py`/ffmpeg 占用；Windows 本地测试时返回 unavailable。 |

网页的 NPU 占用当前是估算值：`最近一次 NPU 推理耗时 * 实际分析 FPS / 1000`。板端当前没有稳定暴露真实 NPU 硬件利用率的 sysfs/debugfs 节点，因此不显示伪造的硬件计数器。

## HTTP API

HTTP 页面、静态资源和 API 均由 `k1edge.app` 的 Flask 应用提供。主要接口：

| API | 作用 |
| --- | --- |
| `/` | 前端主页。 |
| `/static/*` | 前端 JS/CSS。 |
| `/api/preview-snapshot` | 最新高清 JPEG；请求不排队、不返回历史分片。 |
| `/audio/*` | 录音或 YAMNet 保存的音频文件。 |
| `/api/status` | 主状态接口，包含摄像头、视觉、YAMNet、资源、昼夜和 summary 指标。 |
| `/api/healthz` | 轻量健康检查接口，包含进程、配置和 worker 状态摘要。 |
| `/api/detections` | 最新视觉识别结果。 |
| `/api/snapshot` | 最新低清分析 JPEG。 |
| `/api/audio/record` | 手动录音接口。 |
| `/api/audio/yamnet` | 手动触发 YAMNet 检测接口。 |
| `/api/audio/playback` | 播放最近录音缓冲，用于验证麦克风到耳机外放链路。 |

## NPU 移植状态

NPU 相关逻辑统一放在：

```text
ai/runtime.py
```

当前生产配置只保留 K1 INT8 姿态模型：

```text
POSE_MODEL=/home/z/.brdk_models/pose/yolov8n-pose-k1-320-int8.onnx
POSE_PROVIDER=SpaceMITExecutionProvider
POSE_PROVIDER_FALLBACK=0
ANALYSIS_FPS=20
```

`SpaceMITExecutionProvider` 无 CPU fallback，避免模型静默落到 CPU 后造成帧率下降。
## `k1edge/`

主应用层。原则：对外保持旧 API，对内提供清晰 runtime facade。

| 文件 | 作用 |
| --- | --- |
| `k1edge/config.py` | typed dataclass 配置。保持默认值 -> `config.json` -> 环境变量 -> CLI 参数优先级。 |
| `k1edge/runtime.py` | `VideoRuntime`、`AudioRuntime`、`HardwareRuntime`、`DatasetRuntime`、`StatusAggregator` 和 `AppRuntime`。 |
| `k1edge/app.py` | Flask 主服务和数据集服务 route factory。 |
| `k1edge/runtime_store.py` | runtime JSON 状态读写、atomic write、schema version、age/stale helper。 |
